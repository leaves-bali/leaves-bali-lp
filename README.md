# leaves-bali-lp

Leaves Bali のランディングページと顧客管理ダッシュボード。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ランディングページ（資産戦略診断LP） |
| `dashboard.html` | 顧客管理ダッシュボード（CRM） |
| `supabase-schema.sql` | ダッシュボード用のデータベース定義 |
| `logo.jpg` | ロゴ画像 |

## 顧客管理ダッシュボード（dashboard.html）

`dashboard.html` をブラウザで開くだけで動作します。**メールアドレスとパスワードを知っている人だけがログイン**できる認証ゲート付きです。

### 主な機能

- **ログイン認証** … メール＋パスワードでログインした人のみ利用可能
- **対応状況トラッキング（ボールはどちらに？）** … 顧客ごとに「要対応（あなたの番）」「先方の返信待ち」を管理。ダッシュボードの最上部に「今あなたが動くべき顧客」と「返信待ちの顧客」を一覧表示。返信待ちが一定日数を超えると「催促どき」を自動表示。対応記録を追加すると最終接触日が自動更新されます
- **メール作成（Gmail）** … 顧客詳細の「メール」ボタンから、フォローアップ／書類のお願い／日程調整のテンプレートでGmail作成画面をワンクリックで開けます（宛先・件名・本文を自動入力）
- **ダッシュボード** … アクティブ顧客数・進行中案件・成約売上・成約率のKPI、月別売上・サービス別売上グラフ、直近の予定と未完了タスク
- **顧客管理** … 顧客の登録・編集・削除、ステータス／流入元／担当者／タグ管理、検索・絞り込み、顧客ごとの詳細画面
- **案件パイプライン** … 資産戦略レポート・銀行口座開設・PMA法人設立・不動産仲介の進捗をステージ別カンバンで管理（ドラッグ＆ドロップでステージ移動）
- **売上予測** … 各ステージの受注確度で加重した「加重売上予測」をパイプライン画面に表示
- **カレンダー** … 商談・電話・訪問・期限などの予定を月表示で管理
- **タスク** … 期限・優先度つきToDo、期限超過アラート
- **対応履歴・メモ** … 顧客ごとの対応ログをタイムライン表示
- **ダークモード** … 画面右上の 🌙/☀️ ボタンで切替（設定は記憶されます）
- **顧客カルテの印刷/PDF** … 顧客詳細画面の「印刷/PDF」ボタンから出力
- **キーボードショートカット** … `/` で検索、`n` で新規顧客、`Alt+d` でダークモード切替

### Googleカレンダー連携（設定不要ですぐ使えます）

画面右上の「⋯」メニューや各予定から、Googleカレンダーと連携できます。**Google側の面倒な初期設定は不要**です。

- **予定を1件ずつGoogleカレンダーへ** … 予定の編集画面／カレンダー詳細の「Googleカレンダーに追加」ボタンを押すと、Googleカレンダーの登録画面が開きます
- **全予定をまとめて書き出し（.ics）** … 「⋯」→「全予定を書き出し (.ics)」。ダウンロードした `.ics` ファイルをGoogleカレンダーやiPhoneカレンダーに読み込めば、全予定を一括で取り込めます

> 📅 **より本格的な「双方向リアルタイム同期」**（CRMとGoogleカレンダーが自動で同期）も実装可能です。ただしGoogle Cloud側でのOAuth設定と、サイトを正式なURLで公開することが前提になります。ご希望の場合は設定をお手伝いします。

### データ管理（バックアップ・CSV）

画面右上の「⋯」メニューから：

- **全データをバックアップ (JSON)** … すべてのデータを1ファイルに書き出し
- **バックアップから復元** … 書き出したJSONを読み込んで復元
- **顧客をCSVで書き出し／取り込み** … Excelやスプレッドシートとやり取り可能（既存顧客リストの一括取り込みにも対応）

### 動作モード

#### 1. デモモード（初期状態・設定不要）

そのまま `dashboard.html` を開くと、サンプルデータでデモモードとして動作します。データはブラウザ内（localStorage）に保存されます。

- テスト用ログイン … `owner@leaves-bali.jp` / `leavesbali2026`
- ログイン情報は、左下「Supabase 連携設定」から変更できます（このブラウザにのみ保存）

> ⚠️ デモモードの認証はブラウザ内で完結する簡易ゲートです。**複数人・複数端末で共有する本番運用では、下記のSupabase連携を必ず設定してください。**

#### 2. 本番モード（Supabase 連携）

クラウドDBと同期し、複数のスタッフ・端末でデータを共有できます。ログインは Supabase Auth による正式な認証になります。

**セットアップ手順**

1. [Supabase](https://supabase.com/) でプロジェクトを作成
2. Supabase の **SQL Editor** で、同梱の `supabase-schema.sql` を実行してテーブルを作成
3. **Authentication → Users** で、ログインを許可するスタッフのメールアドレス／パスワードを登録
4. **Project Settings → API** から `Project URL` と `anon public` キーを取得
5. `dashboard.html` を開き、左下の「**Supabase 連携設定**」に URL とキーを入力して保存
6. 登録したメールアドレスとパスワードでログイン

以降、そのブラウザは Supabase と同期して動作します（接続状態は左下のインジケータで確認できます）。

### 公開方法

静的ファイルのみで動作するため、GitHub Pages や任意の静的ホスティングにそのまま配置できます。認証をかけたい場合は上記のSupabase連携を利用してください。
