「AIが勝手なことを書く」が起きない理由

返信はGoogleマップに残り続けます。取り返しがつかないからこそ、止まる仕組みを先に入れてあります

✓
全件が下書きで止まる
自動公開は既定で切ってあります。人が押さないかぎり1件もGoogleには出ません。
✓
返金や補償を約束しない
金銭の判断はホテル様のものです。AIには書かせない制約を入れています。
✓
危ないクチコミは隔離する
低評価、衛生・盗難・法的措置の主張、返金要求は「要確認」に分けます。
✓
事実を作らない
いただいた情報にない設備・サービス・スタッフ名には触れません。

インドネシア語は現地の言い回しをAIに任せきれないため、自動公開の対象から外しています。対応5言語以外のクチコミも「要確認」に回ります。
