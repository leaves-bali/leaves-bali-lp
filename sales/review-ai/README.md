# クチコミ返信AI 営業資料

飲食店・ホテルの両方に使える営業用の資料です。

| ファイル | 用途 |
|---|---|
| `kuchikomi-reply-ai.pdf` | **商談本番用。** 9ページ・16:9 |
| `slides.html` | 資料の元データ。これを編集してPDFを作り直します |

## 方針

- **価格は載せていません。** 相手と状況で変わるため、口頭で提示します
- **5ページ目で「できないこと」を先に開示**しています。Google以外は「AIが書く・人が貼る」です。
  導入後に「話が違う」となるほうが損失が大きいため、先に出しています
- 訴求は売上増ではなく**コスト削減と時間**。中小企業のAI導入を阻む1位は
  「何から始めればいいか分からない」（62%）で、反対されているわけではないため、
  説明より体験デモを見せる構成にしています

## 作り直し方

```bash
node build.mjs     # slides.html を Chromium で PDF 化
```

playwright が必要です（このリポジトリの依存には含まれていません）。
ブラウザ本体は `/opt/pw-browsers` のものを `executablePath` で直接指定しています。

生成前に、全スライドが 1280x720 に収まっているか（はみ出し・JSエラー）を
検査して結果を出力します。

## 出典（資料内の数字）

| 数字 | 出典 |
|---|---|
| 中小企業のAI導入率 20.4%／検討中 18.6% | 中小企業基盤整備機構「中小企業のAI等の利活用に係る実態調査」2026年3月 |
| 大企業の導入率 42〜48% | Leach「中小企業AI導入実態調査2026」 |
